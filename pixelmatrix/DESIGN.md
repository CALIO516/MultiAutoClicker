# PixelMatrix Studio — Design system v1.2

이 문서는 사용자가 제공한 awesome-design-md-main.zip의 `linear.app/DESIGN.md`, `figma/DESIGN.md`, `apple/DESIGN.md`의 디자인 원칙을 PixelMatrix 제품 UI 요구사항에 맞게 재구성한 독자 규칙입니다. 특정 서비스의 이미지, 고유 폰트, 브랜드 UI 자산은 사용하지 않습니다.

## 원칙
- 캔버스 우선: 편집 화면 진입 시 작업 캔버스가 가장 먼저 보이고 나머지는 접힌 탭 안에서 접근합니다.
- 모드 분리: 편집 / 도구 / GIF / 기기의 하단 4탭. 연결 상태는 기기 탭의 녹색 점으로만 표현합니다.
- 하나의 강조 색상: 클릭 가능한 주요 액션에만 라벤더를 사용합니다. 연결 성공은 민트 색상으로 표시합니다.
- 밝은 글자와 얇은 1px 테두리: 어두운 면의 계층을 네 단계 내에서 구분하고 두꺼운 글로우, 장식용 그라데이션, 과도한 그림자를 피합니다.
- 화면 안전영역: Android 상태바 및 내비게이션바를 침범하지 않고, 하단탭에 safe-area inset을 더합니다.
- 캔버스 내부 제스처: 핀치 확대와 이동은 `.canvasViewport`에서만 처리되며 화면 전체 줌을 유도하지 않습니다.

## 색상 토큰
- Canvas `#090B10`, surface `#141720`, elevated `#1A1E29`, control `#1B1F2A`
- Border `#292E3C`, text `#F3F4F8`, secondary `#A7ADBE`
- Action lavender `#939AFF`, success `#59D6A1`, warning `#FFB9C4`

## 컴포넌트 규칙
- 터치 타겟 42px 이상 (대표 버튼 44px 권장), 기본 라운드 10px, 카드 라운드 13–14px
- 모바일 제목 15–17px, 텍스트 12–14px, 보조글자 10–11px. 외부 폰트 파일 없이 시스템 폰트 사용.
- 작업 버튼은 모바일 상단에서 가로 스크롤. 화면 전체의 가로 스크롤은 금지.
- GIF 변환의 옵션·기기 제어의 옵션은 내부 카드를 사용하고 긴 옵션은 폭 안에서 개행.
- 시스템 기능의 성공 메시지는 시각 장식보다 의미 있는 연결 상태 텍스트를 우선.

## 검증
정적 소스 검사 및 Android 컴파일. 실제 기기 UI 자동 미리보기·실행 없음. BLE 실기기 제어 미검증.
