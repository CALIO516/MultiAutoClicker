# PixelMatrix Studio v1.2

사용자가 제공한 74개 DESIGN.md 디자인 시스템 모음을 참고해 PixelMatrix Studio v1.1의 화면을 정리한 Android 독립 버전입니다. 이전 v1.1의 픽셀 편집·GIF 변환·LED BLE 기능은 유지했습니다.

## v1.2 UI 변경
- 저채도 다크 배경 / 라벤더 단일 주요 강조색 / 최소 테두리와 그림자
- 모바일 헤더 축소 및 상단 프로젝트 명령 가로 스크롤 (화면 자체 가로 스크롤 없음)
- 캔버스 중심 편집 레이아웃, 확대 기능은 캔버스 내부에서만 유지
- 모바일 하단 4개 탭: 편집·도구·GIF·기기. 기기 연결 시 탭 연결 표시
- 모바일 펜과 도구 버튼 확대, PNG/GIF 저장 버튼 양쪽 균등 배치
- 상태바/탐색바 안전영역 유지, 글꼴 외부 다운로드 없음

## 설치
GitHub Actions 빌드의 디버그 서명이 이전 APK와 다를 수 있어 v1.2는 별도 패키지 `com.pixelmatrix.studio.v12`로 설치됩니다. 기존 v1.1 프로젝트 데이터는 v1.1에서 프로젝트 저장 후 v1.2에서 불러오기 하세요.

## 참고 및 제한
디자인 자료 중 `linear.app`, `figma`, `apple`의 색상 계층·작업 중심 구조·모바일 사용성을 기능에 맞게 재구성했습니다. 원본 브랜드 자산이나 폰트는 포함하지 않았습니다. 소스 정적 검사 및 APK 빌드만 수행했고, 실제 화면 미리보기 실행/실기기 BLE 연결 테스트는 하지 않았습니다.
