# PixelMatrix Studio v2.0 · 16-bit Collection

## 전면 갱신된 움직이는 LED 픽셀 아트
- 기존 저품질 100종 전부 교체: 새롭게 제작한 200개, 20개 분류 × 10개.
- 모든 GIF 32×32 RGB, 8프레임, 125ms 프레임 속도, 무한 반복.
- 고전게임 감성: 픽셀 명암/하이라이트/광원/배경 깊이/반사광/도트 기반 컬러 그라데이션.
- 안내 글꼴: 비트맵 3×5 영문 전용 글꼴, 문구마다 판넬 내부에 맞춰 크기 자동 제한.
- 매장 안내에서는 OPEN, CLOSED, SALE, EXIT, WIFI, WC, INFO, 24H, PARK, PICKUP 등 짧고 읽을 수 있는 표현만 사용.
- 아케이드 / 판타지 RPG / 액션 / 우주 / 사이버펑크 / 카페 / 식당 / 매장 안내 / 교통 / 공사 / 날씨 / 자연 / IT / 업무 / 음악 / 오브젝트 / 스포츠 / 도시 / 축하 / 게임 HUD.

## 앱 라이브러리
- GIF 메뉴에서 **분류 선택** 드롭다운 또는 가로 카테고리 칩으로 200종 필터.
- 이름 검색, 애니메이션 썸네일, 큰 픽셀 미리보기, 편집기에 가져오기, GIF 저장, LED 직접 전송.
- 미리보기 표시 개수를 20개씩 추가하여 모바일 성능과 메모리 절약.
- 기존 편집·수정·블루투스 제어 기능 유지.

## 검증 범위
- APK 빌드 / 내부 파일 수 / GIF 구조·프레임·지연시간 / JS 구문 정적 검사.
- 실기기 화면과 LED 전송은 실사용 확인 필요. 테스트용 미리보기 실행 없음.
- 저작권 있는 게임 캐릭터·IP를 모방하지 않는 신규 오리지널 디자인.
- Android 8.0+, 패키지 com.pixelmatrix.studio.v20 (기존 1.3과 별도 설치).
