# PixelMatrix Studio v1.1 — Android 독립 앱

별도 설치 앱 `com.pixelmatrix.studio.v11` · Android 8.0 이상 · 인터넷 불필요.

기존 v1.0과 서명키가 달라 덮어쓸 수 없으므로 v1.1은 별도 설치됩니다. 기존 v1.0에서 **프로젝트 저장** 후 v1.1에서 **프로젝트 불러오기**로 데이터를 옮길 수 있습니다.

## 바뀐 기능
- 화면 상단 상태바 및 하단 시스템 탐색바를 침범하지 않도록 Android UI 처리 수정.
- 모바일 고정 하단 탭: 편집 / 그리기 도구 / GIF·샘플 / LED 기기. 연결 메뉴는 화면 상단과 LED 탭에서도 접근 가능.
- 캔버스 안에서만 확대·축소 및 이동. 100~800% 확대. 두 손가락 확대와 `이동` 버튼으로 팬 이동. 전체 페이지는 확대하지 않음.
- LED BLE 검색·연결 상태 표시, 최근 연결 기기 재연결.
- 실제 BLE 전송 단위(MTU)를 반영하고 쓰기 결과 확인. 연결 끊김에 대한 안내 강화. 4KB 외부 청크의 최초/이어쓰기 플래그 수정.
- LED 시계(8 스타일·날짜·24h), 휴대폰 시각 동기화, 조명 효과 7종, 회전, 카운트다운, 스톱워치, 점수판, 절전 시간대, 밝기, 전체 색상, 전원, GIF/정지 이미지 업로드.
- 텍스트는 픽셀 아트로 변환해 표시하며 움직이는 텍스트는 GIF를 이용.

## 사용법
1. 앱을 실행하고 하단 **LED 기기**를 터치하거나 상단 **기기 연결** 버튼을 터치합니다.
2. 공식 iDotMatrix 앱이 기기에 연결 중이라면 먼저 연결을 끊습니다.
3. 근처 기기 권한을 허용합니다. 주변 BLE 목록에서 iDotMatrix 장치를 골라 연결합니다.
4. LED 기기 화면에서 '연결됨' 표시를 확인한 후 전원·시계·밝기 등을 사용하거나 픽셀 그림을 전송합니다.
5. 편집 탭에서 확대는 `＋`, `−`, `원래 크기`. 이동은 `✥ 이동` 버튼 또는 두 손가락 제스처를 사용합니다. 확대는 캔버스 내부로만 제한됩니다.

## 검증 범위
Android SDK 컴파일은 GitHub Actions로 검증할 수 있습니다. 실제 iDotMatrix 하드웨어에서 BLE 제어·GIF 업로드는 아직 확인되지 않았습니다. 제품·펌웨어마다 프로토콜이 다를 수 있습니다.
