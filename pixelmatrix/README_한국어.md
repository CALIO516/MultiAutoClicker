# PixelMatrix Studio v1.3

## UI 정밀 개선
- 휴대폰 상단 4개 버튼: 동일 넓이, 2줄 글꼴, 가로 잘림 방지
- 타임라인/캔버스는 편집 탭에서만 표시. 도구·GIF·기기 탭에서는 편집 전체 화면 숨김
- 제목/버튼 간격 및 터치 영역 재정의, 좁은 화면의 틀 넘침 방지
- 기존 앱 기능과 BLE 제어 유지. Android 상태바·내비게이션 바 영역 유지

## 유의
- Android 8.0 이상. 실제 iDotMatrix 장치와의 BLE 호환은 모델별 실기기 확인 필요.
- 원본 제조사 APK/코드/브랜드 자산을 포함하지 않았습니다. 독립적 픽셀 디자인과 공개 프로토콜을 사용합니다.
- 이전 설치의 서명키가 다를 수 있어 별도 패키지 com.pixelmatrix.studio.v13 적용.
- 미리보기는 실행하지 않았으며 문법, 데이터, 패키지 구조를 정적으로 검증합니다.
